## 回归与类型检查

前后端共 27 个测试文件，包含 **140 个具名用例及 5 组顶层断言脚本检查**，合计 **145 项检查全部通过**，失败和跳过均为 0；新增 21 个具名回归用例。TypeScript `tsc --noEmit` 通过。

后端 129 项，前端 16 项。测试覆盖原生协议消息、参数校验、未知工具、候选白名单、失效 ID、重复调用缓存、工具异常、超时、调用预算、事实查询上下文保持、控制器集成及评测器判分，并保留原有路线与前端回归检查。回归检查通过率和真实模型场景通过率分别统计。

## 迭代记录

1. 最初的两条沙箱网络检查无法连接 API；该报告记录失败，不用于模型质量或成功响应时延结论。
2. 获得网络访问后，协议冒烟发现模型可能先输出 JSON 而跳过可选工具。增加具名事实查询与候选选择的强制核实步骤，保留真实 `tool_calls` / `ToolMessage` 往返。
3. Prompt v1 的完整评测通过 59/60 个场景。唯一未通过项是具名点位同时输出了类别，顺序与名称正确，但不符合该样本的字段约定。首轮原始报告保留在 [v1 结果](../dev/idea-eval-2026-11-09-full/summary.json)。
4. Prompt v2 明确具名与类别的互斥约定，同时保留工具检索对应的 lookup 上下文，完整复测通过 60/60 个场景。不把两次单轮结果的差异解释成稳定提升比例。
