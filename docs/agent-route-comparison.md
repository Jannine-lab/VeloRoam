# 路线推荐与对比

已确认需求进入规划器。必需路段属性只在已有路段标签为 `matched` 时视为满足；`unknown` 不能作为满足的依据。已确认具名路段必须核实同名记录，不能用名称相似的其他路段静默替换。用户指定区域为必须限制且没有可核实边界、要求必须避开某类道路但无法验证连接路段，或者总时间含停留却缺少停留时长时，返回说明与可调整选项，不生成声称已满足条件的路线。旧客户端未携带需求状态时保留兼容行为，但不会声称未知避让已被核实。

候选地点和路段保留用户途经顺序，优先尝试各自的替代候选及双重替换组合，最多比较六个、最多三个同时请求导航。每条路线按实际导航结果检查里程和时间预算。必须满足的独立时间目标在没有明确上下限时按目标上下浮动 10% 验证，并在确认摘要中说明；明确上下限优先。未通过要求的候选不会作为成功路线。

首条路线仍先流式返回；沿途探索先返回符合约束的单个高分路段备选，再尝试组合不同连接区间的两个顺路路段。组合必须重新导航并通过里程、时间、途经顺序、最大额外绕行和重叠检查；组合失败时退回另一条合格的单路段备选。最终比较列出各方案里程、预计时间、较首条的里程差和新增路段；轨迹重复比例为估算，并不代表实地道路条件已经核实。搜索覆盖、道路数据以及导航服务可用性仍会影响结果。
