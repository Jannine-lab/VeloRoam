# 自主路线生成与调试

生成器为没有明确途经点、路段标签或避开条件的往返骑行请求，构造多个不依赖数据库 POI 的坐标方案。每组包含三个自主途经坐标；区域目标作为方向参考，候选参考点可以距解析出的中心最多约 5 公里，并非行政边界判断。对包含多个已确认路段或点位的往返请求，会按原顺序保留这些对象，并在固定对象前后自主生成途经位置；指定路段保持原始轨迹与方向。避开条件及无法生成有效候选时仍使用原有规划流程。

每个方案先用几何位置作为搜索目标，调用现有骑行导航；先验证导航轨迹的终点离搜索目标不超过 100 米，再沿轨迹累计距离采样多个候选点；目标方向参考点额外限制采样点与搜索目标的偏移。选中的轨迹点需要再次通过完整路线的连接验证。所选点和指定路段再拼接成完整路线，已验证的发现轨迹在相同起终点时复用；其他连接仍需骑行导航返回有效轨迹。先尝试 3 个方案，再以符合预算且排序最优的路线为基准；如果没有合格方案，则选与目标最接近的已导航方案作为基准。最多增加 2 个组合，每次仅在一处沿原导航轨迹调整采样位置，其他点和用户指定路段保持不变；每条新路线都重新导航验证。接受结果须符合明确上下限；只有距离目标且未指定上下限时使用上下浮动 10%。对于符合预算的候选，优先使用可以估算重复比例的路线，按 30 米网格估算的重复比例、目标距离偏差和时间偏差依次比较。无法计算重复率时标记为未知，不作为零重复。用户明确表达折返或刷圈偏好时，不因重复道路扣分；若明确要求全程原路返回，由于尚不能验证返程道路方向与一致性，系统会说明无法保证并提供放宽选项。网格估算可能将相邻平行道路误判为重复，不是精确的道路级去重。导航失败、固定途经顺序或路段轨迹验证失败、以及超预算的候选不会作为成功结果。每个导航段端点和相邻轨迹的最大间隔超过 100 米时会拒绝；5～100 米间隔会说明其中的通行尚未验证，不会补画直线。避开条件若无法对连接道路验证，也会明确说明。

本版使用几何算法提出搜索目标，并从骑行导航返回的轨迹选取最终自主点；AI 仍负责理解用户意图，并不是由大模型直接逐点绘制道路。生成器尚未结合道路级拓扑判断重复路段，也没有优化路况或景观；对区域的靠近不证明实际进入该行政区。模型无法验证的体验与道路条件会在结果中说明。

## 本机调试

在 `VeloRoam-api` 目录配置现有高德骑行导航密钥，然后执行：

```sh
ENABLE_ROUTE_DEBUG=true npm run dev
```

浏览器访问 `http://127.0.0.1:3000/dev/route-generator`（如果设置了其他 `PORT`，替换端口）。只允许本机访问，默认关闭。页面上可点击地图设置起点和可选目标方向，也可手动输入 WGS84 坐标，然后设定目标公里数并生成。可以输入公开 Strava 路段 ID 和活跃点位 ID，选择两者的途经顺序，查看固定对象和自主生成点的组合；同时输入固定路段或点位与目标方向时，当前优先固定对象，尚不支持联合验证目标方向。列表展示每个候选的导航距离、时间、重复率估算、调整的是哪个关键点、硬约束结果和比较理由，点击候选可查看其自主点位及实际导航轨迹。每次请求的导航次数随固定对象数量增加；最多 8 个固定对象时约 61 次，两个固定对象时约 31 次，请注意地图服务配额与等待时间。

底图使用 OpenStreetMap 在线瓦片，需要浏览器可以访问互联网。高德返回的导航轨迹转换为 WGS84 再绘制；实心橙色点为从导航轨迹选出的关键点；打开“显示关键点来源导航轨迹和搜索目标”后，空心橙色点为初始搜索目标，蓝色虚线为点位来源轨迹，沿线标记表示不同距离比例的采样候选；候选可在列表展开查看选择或排除原因。这些点不表示已经识别出路口，地图上的绿色或蓝色线条是导航实际返回的连接轨迹，紫色线条是所选路段的原始轨迹。
