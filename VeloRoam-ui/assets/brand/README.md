# 循迹 · VeloRoam

「循迹」寓意循着路线探索，也呼应骑行途中留下的轨迹。环线、山形和箭头代表骑行路线、地形与前行。深色背景和绿色呼应应用现有地图界面。

- `logo.svg`：横版中英文组合标志；引用同目录下的 `app-icon-1024.png`，使用时请一并复制。
- `app-icon-1024.png`、`app-icon-512.png`、`app-icon-192.png`：方形应用图标。
- `apple-touch-icon.png`：180 × 180 图标。
- `favicon-32.png`：32 × 32 浏览器图标。
- `app-icon-source.png`：图像生成原图。

图形使用内置 imagegen 生成，提示词：为骑行路线探索应用设计深炭黑背景、荧光绿色的简洁图标，以环形路线、山形和箭头表达探索与前行，无文字。组合标志使用 SVG 排版，图形本身为位图。名称和图形在正式商业使用前应自行核查商标及其他权利。
